# Design system Wear

Tokens reaproveitados do MARK: ciano #79DDE0, texto secundário #91A4B4; adaptação para preto predominante #05080B e painéis #122027. Textos brancos; sem neon, animação contínua ou emoji como ícone. Glyph é desenho vetorial, com traços consistentes para microfone, saúde, estado e configurações.

WearUi centraliza página rolável, títulos, valores, labels de estado e botões arredondados. Tela redonda usa insets laterais de 30dp; retangular 16dp. Botões de pelo menos 48dp; layout depende da densidade/configuração reais. Orientação preserva a página via estado Android.

Home reúne conexão/PC/bateria e entradas ASK/HEALTH/STATUS/ACTIONS/SETTINGS. ASK diferencia LISTENING (reconhecedor externo), PROCESSING, ANSWER READY e erro. Offline e indisponibilidade são texto explícito; sem valores simulados.

Qualidade visual no TicWatch permanece UNVERIFIED. Não houve emulador ou inspeção de screenshot real. Conferir clipping de tela redonda, escala de fonte, teclado, comprimento de respostas e orientação na campanha física. Um build bem sucedido não prova acabamento visual.
